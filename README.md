# ComplyErg v2 — Legal Metrology Label Compliance Engine

**ComplyErg** is an offline-capable, production-grade Legal Metrology label-compliance scanning system for the Indian **Legal Metrology (Packaged Commodities) Rules, 2011**, specifically enforcing **Rules 6, 7, 9, and 10**.

The system takes a photo of a packaged product label, extracts mandatory legal declarations, evaluates them against legal rules deterministically, logs audit trails, and produces explainable compliance reports and executive risk analytics.

---

## 🏛️ Hard Scope Boundary & Core Principles

1. **Mandatory Declaration Verification Only (Rules 6, 7, 9, 10)**:
   - Validates statutory legal declarations (Manufacturer/Packer, Net Quantity, MRP, Mfg & Expiry Dates, Consumer Care, Batch No, FSSAI Lic, Country of Origin).
   - Ingredients declaration is checked **only for presence** (`ingredients_declared: {present: bool, confidence, bbox}`) — **never** for ingredient content, nutrition, or health claims.
2. **Deterministic Legal Verdicts**:
   - 100% explainable legal verdicts generated by the generic Rule Engine (`app/pipeline/rule_engine.py`) against versioned rule JSON specifications (`legal_metrology_2011.json`). ML models perform quality gating, field classification fallback, and audit risk scoring.
3. **Three-Tier Role-Based Access Control (RBAC)**:
   - **Inspector**: Upload/scan photos, view own scan results, export own PDF/CSV/JSON reports. DB queries strictly filtered by `user_id`.
   - **Supervisor**: View team/region scans, override field values (requires mandatory `reason` logging to `AuditLog`), view team dashboard & audit logs.
   - **Admin**: Full system access (global view, edit rules, manage users, delete scans, view full audit log & global dashboard).
4. **Atomic Audit Logging**:
   - Every field override, scan deletion, rule modification, or user role update atomically logs an `AuditLog` record in the same database transaction.

## ⚡ Quickstart Guide

### 1. Environment Setup
```bash
# Activate existing environment or create new venv
python -m venv ocr_env
ocr_env\Scripts\activate

pip install -r requirements.txt
```

### 2. Database Initialization
```bash
python -c "from app.db.init_db import init_db; init_db()"
```
*Seeds database with default Admin, Supervisor, and Inspector users and 15 statutory Legal Metrology rules.*

### 3. Running Backend API & Streamlit Web Portal

**Terminal 1 — FastAPI Backend**:
```bash
uvicorn app.main:app --reload --port 8000
```
*Interactive Swagger docs available at `http://localhost:8000/docs`*

**Terminal 2 — Streamlit Frontend**:
```bash
streamlit run streamlit_app/Home.py
```
*Open browser at `http://localhost:8501`*
